# 유스케이스

룸링크(coliving-platform)에서 방문자, 회원, 입주민, 관리자가 수행하는 목표입니다.
기준은 `frontends/user-web` 화면과 `frontends/admin-web` 메뉴입니다.
입주 계약의 호출 순서는 [계약 시퀀스](계약-시퀀스.md)에 있습니다.

다이어그램은 Mermaid 12.0.0 이상의 `usecase-beta` 문법입니다. 이 문법은 베타라서 이후 버전의 표기가 바뀔 수 있습니다. Mermaid 11 이하에서는 렌더되지 않습니다.

## 액터

| 액터 | 설명 |
|------|------|
| 방문자 | 로그인하지 않은 사용자. 매물 조회, 회원가입, FAQ, 비회원 문의 |
| 회원 | 로그인한 사용자. 입주 신청, 계약 서명, 결제, 프로필 |
| 입주민 | 입주 상태가 있는 회원. 커뮤니티와 공용시설 예약 |
| 관리자 | admin-web 운영자 |
| 메일 | 가입 이메일 인증 |
| 포트원 | 계약 서명의 본인인증 |
| 카카오페이 | 계약금 결제 |

입주민은 회원의 특화 액터입니다. 일반화 화살표는 특화 액터에서 일반 액터로 향합니다.

## 개요

```mermaid
usecase-beta
direction LR
actor Guest("방문자")
actor Member("회원")
actor Resident("입주민")
actor Admin("관리자")
actor Mail("메일")
actor PortOne("포트원")
actor KakaoPay("카카오페이")
systemBoundary roomlink["룸링크"]
  Browse("매물 조회")
  SignUp("회원가입")
  Apply("입주 신청")
  SignContract("계약서 서명")
  Pay("계약금 결제")
  UseCommunity("커뮤니티 이용")
  BookFacility("공용시설 예약")
  OperateResidents("입주자 운영")
  ManageProperty("매물 관리")
  ManageDocs("계약 문서 관리")
  OperateResources("공용 자원 운영")
end
Resident --|> Member
Guest --> Browse
Guest --> SignUp
Member --> Browse
Member --> Apply
Member --> SignContract
Member --> Pay
Resident --> UseCommunity
Resident --> BookFacility
Admin --> OperateResidents
Admin --> ManageProperty
Admin --> ManageDocs
Admin --> OperateResources
SignUp --> Mail
SignContract --> PortOne
Pay --> KakaoPay
```

## 계정, 매물, 계약

회원가입은 이메일 인증을 항상 포함합니다.
입주 신청은 호실 상세 조회를 항상 포함합니다.
계약서 서명은 본인인증을 항상 포함합니다.
계약 정보 자동완성은 계정 설정의 선택 확장입니다.

```mermaid
usecase-beta
direction LR
actor Guest("방문자")
actor Member("회원")
actor Mail("메일")
actor PortOne("포트원")
actor KakaoPay("카카오페이")
systemBoundary account["계정 매물 계약"]
  BrowseBuildings("건물 목록 조회")
  ViewRoom("호실 상세 조회")
  SignUp("회원가입")
  VerifyEmail("이메일 인증")
  Login("로그인")
  EditProfile("프로필 관리")
  AccountSettings("계정 설정")
  Autofill("계약 정보 자동완성")
  Apply("입주 신청")
  ViewApplication("입주 신청 조회")
  SignContract("계약서 서명")
  VerifyIdentity("본인인증")
  Pay("계약금 결제")
end
Member --|> Guest
Guest --> BrowseBuildings
Guest --> ViewRoom
Guest --> SignUp
Guest --> Login
Member --> EditProfile
Member --> AccountSettings
Member --> Apply
Member --> ViewApplication
Member --> SignContract
Member --> Pay
SignUp ..> : include VerifyEmail
Apply ..> : include ViewRoom
SignContract ..> : include VerifyIdentity
Autofill ..> : extend AccountSettings
VerifyEmail --> Mail
VerifyIdentity --> PortOne
Pay --> KakaoPay
```

## 커뮤니티, 공용시설

게시글 신고는 게시글 조회의 선택 확장입니다.
댓글 작성은 게시글 조회를 항상 포함합니다.
FAQ 문의와 비회원 문의는 로그인 없이 할 수 있습니다.

```mermaid
usecase-beta
direction LR
actor Guest("방문자")
actor Resident("입주민")
systemBoundary living["커뮤니티 공용시설"]
  AskFaq("FAQ 문의")
  GuestInquiry("비회원 문의")
  ReadPost("게시글 조회")
  WritePost("게시글 작성")
  Comment("댓글 작성")
  SendNote("쪽지 보내기")
  Chat("채팅")
  BlockUser("사용자 차단")
  ReportPost("게시글 신고")
  ReadNotice("알림 확인")
  BookFacility("공용시설 예약")
  ViewReservations("예약 내역 조회")
end
Guest --> AskFaq
Guest --> GuestInquiry
Resident --> AskFaq
Resident --> ReadPost
Resident --> WritePost
Resident --> Comment
Resident --> SendNote
Resident --> Chat
Resident --> BlockUser
Resident --> ReadNotice
Resident --> BookFacility
Resident --> ViewReservations
Comment ..> : include ReadPost
ReportPost ..> : extend ReadPost
```

## 관리자

admin-web 사이드바의 운영 목표입니다.

```mermaid
usecase-beta
direction LR
actor Admin("관리자")
systemBoundary adminweb["운영"]
  Login("로그인")
  ViewDashboard("운영 현황 조회")
  MonitorSystem("시스템 모니터링")
  ManageContracts("계약서 관리")
  ManageForms("문서 양식 관리")
  ManageResidents("입주자 관리")
  ViewCalendar("입주·퇴거 일정 조회")
  ReplyNotes("쪽지 응대")
  HandleReports("신고 처리")
  ManageFaq("FAQ 문서 관리")
  ManageProperty("매물 관리")
  ManageResources("공용 자원 관리")
  ManageReservations("예약 관리")
  ManageOverdue("연체 관리")
  QrCheckIn("QR 체크인")
end
Admin --> Login
Admin --> ViewDashboard
Admin --> MonitorSystem
Admin --> ManageContracts
Admin --> ManageForms
Admin --> ManageResidents
Admin --> ViewCalendar
Admin --> ReplyNotes
Admin --> HandleReports
Admin --> ManageFaq
Admin --> ManageProperty
Admin --> ManageResources
Admin --> ManageReservations
Admin --> ManageOverdue

```

## 표기

| 표기 | 의미 |
|------|------|
| 실선 화살표 | 액터와 유스케이스의 연관 |
| `..> : include` | 기준 유스케이스가 대상 유스케이스를 항상 포함. 그림에는 «include» |
| `..> : extend` | 출발 유스케이스가 기준 유스케이스를 조건부로 확장. 그림에는 «extend» |
| 일반화 화살표 | 특화 액터에서 일반 액터로 향한다. 입주민은 회원이다 |
